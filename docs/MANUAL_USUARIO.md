# Manual — fase 1

Ingresar en `/admin/` con una cuenta activa y acceso administrativo. No existe
registro público. Cerrar sesión con el botón de la cabecera.

Trabajadores: buscar por fragmento de nombre o DNI, filtrar activos, agregar con
nombre solamente. Si aparece coincidencia, revisar si corresponde reactivar antes
de confirmar una ficha independiente. Editar Activo para desactivar/reactivar.

Catálogos: administradores pueden crear, editar y desactivar. Mantener códigos
como texto (01). En operaciones, Desconocido indica una regla de fecha final aún
no revisada. Los grupos especiales no calculan saldos.

Periodos: ingresar fechas reales del corte; puede quedar el fin vacío. Ante
solapamiento, revisar y justificar en Notas antes de autorizar. Cerrar o procesar
mediante Estado; el servidor registra fechas y auditoría. Se conservan fechas de
transiciones anteriores al reabrir. No inferir mes natural a partir del título.

Administradores consultan Historial de cambios y gestionan Usuarios/Grupos.
Operadores editan trabajadores. Consulta no puede escribir. No hay aún registro
web de justificaciones ni carga de Excel ni exportación.
